How it works

Online forms often reject a photo that is a few KB too large. This tool shrinks your image to the limit you type in, so you do not have to try several apps.

It works in your browser, so your photo is never sent to a server. You can also set the width and height in pixels if your form asks for them.

Always follow the exact size and format written in your official notification. Limits differ between exams and years.

Common questions

Is my photo uploaded anywhere?

No. The image is processed inside your browser tab and is gone when you close the page.

Which file type do I get?

A JPG, which is the format most application forms accept.

What if the form wants a different size?

Type any KB value in the custom size box. You can also enter width and height in pixels.
